# Lime Apps

Лёгкий набор настольных приложений на C, созданный прежде всего для **LimeOS**.
Также работает на Arch/Omarchy, Debian/Ubuntu и Fedora.
Пять отдельных программ, системный GTK 3, локальные данные и никаких фоновых служб.
Это независимый проект сообщества; он не является официальным компонентом LimeOS.

| Приложение | Что умеет |
| --- | --- |
| **LimeCalc** | Выражения, скобки, степени, проценты, `sqrt`, `pi`, `e`, история и вычисления из терминала |
| **LimeNotes** | Заметки с заголовками, поиск и автоматическое сохранение |
| **LimeTasks** | Задачи, отметки выполнения, фильтры и отмена удаления |
| **LimeView** | Изображения, масштабирование, поворот и переход между файлами папки |
| **LimeClock** | Местное время, календарь, секундомер и таймер обратного отсчёта |

LimeFiles здесь нет: это уже существующее приложение.

## Внешний вид

В заголовке каждого приложения есть четыре темы:

- **System** — следовать настройке системы: desktop portal, GNOME color-scheme или GTK.
- **Light** — светлая монохромная.
- **Dark** — тёмная монохромная.
- **Lime** — тёмная с лаймовым акцентом.

По умолчанию выбрана системная тема. Выбор сохраняется для набора и используется
при следующем запуске любого приложения. При открытых приложениях каждый
переключатель меняет тему своего окна. Системная тема реагирует на изменение
настройки системы без перезапуска, когда рабочий стол сообщает о нём через GTK,
GSettings или portal.

## Скачать и установить

Готовые пакеты для **x86_64**: [GitHub Releases](https://github.com/shidikusik/lime-apps/releases/latest).
Первая публикация появляется после успешной сборки и проверок GitHub Actions.
Системный менеджер пакетов устанавливает нужные библиотеки GTK автоматически.

**Arch Linux / Omarchy:**

```sh
sudo pacman -U ./lime-apps-*.pkg.tar.zst
```

**Debian / Ubuntu и совместимые системы:**

```sh
sudo apt install ./lime-apps_*.deb
```

**Fedora:**

```sh
sudo dnf install ./lime-apps-*.rpm
```

Базовые цели выпуска: текущий Arch, Ubuntu 22.04+, Debian 12+ и Fedora 43+.
CI собирает `.deb` на Ubuntu 22.04, проверяет его установку и запуск на Debian 12
и Ubuntu 24.04, отдельно собирает и проверяет RPM на Fedora 43 и пакет Arch.
Совместимость с производными системами зависит от наличия этих системных библиотек.
Omarchy использует пакет Arch; отдельная проверка рабочего стола выполняется локально.
Исходники можно собрать для других архитектур; готовые пакеты первого выпуска — x86_64.

Скачав все файлы выпуска в одну папку, проверь их:

```sh
sha256sum -c SHA256SUMS
```

Приложения появятся в меню. Команды: `lime-calc`, `lime-notes`, `lime-tasks`,
`lime-view [изображение]`, `lime-clock`.

## Собрать из исходников

Нужны C-компилятор, Make, pkg-config, GTK **3.24+** и GLib **2.66+** с заголовками.
WebView, Electron, Node.js, Python и сетевые службы для работы приложений не нужны.

```sh
# Arch / Omarchy
sudo pacman -S --needed base-devel gtk3 pkgconf

# Debian / Ubuntu
sudo apt install build-essential pkg-config libgtk-3-dev

# Fedora
sudo dnf install gcc make pkgconf-pkg-config gtk3-devel
```

Выполни строку для своего дистрибутива, затем:

```sh
git clone https://github.com/shidikusik/lime-apps.git
cd lime-apps
make -j2
make test
make install PREFIX="$HOME/.local"
```

`$HOME/.local/bin` должен находиться в `PATH`. Удаление такой установки:
`make uninstall PREFIX="$HOME/.local"`. Для системной установки: `sudo make install`.
Рецепты пакетов находятся в `packaging/`; для Arch предпочитай checksummed
`PKGBUILD` из выпуска. Данные пользователя при удалении не стираются.

## Клавиши и ограничения

- **Calc:** Enter — вычислить, Esc — очистить. `lime-calc --eval 'sqrt(81)+2^3'`
  работает без графического сеанса. Проценты означают деление операнда на 100.
- **Notes:** Ctrl+N — создать, Ctrl+S — сохранить, Ctrl+F — поиск.
- **Tasks:** Ctrl+N — ввод новой задачи, Ctrl+S — сохранить. После удаления есть Undo.
- **View:** Ctrl+O — открыть, стрелки — предыдущий/следующий, Ctrl+колесо — масштаб,
  F11 — полный экран. Поддерживаемые форматы определяются установленными GdkPixbuf
  loaders; GIF отображается как неподвижное изображение. Поворот меняет просмотр,
  исходный файл не перезаписывается. Для больших изображений используется
  уменьшенное превью; лимиты — 128 MiB на файл и 64 мегапикселя.
- **Clock:** таймер работает, пока окно открыто; после закрытия приложение завершается.
  Он показывает завершение в окне и подаёт системный сигнал, если он поддерживается.

Интерфейс первой версии на английском. Для пробного запуска с определённой темой
без изменения сохранённого выбора: `LIME_THEME=light lime-calc`
(`system`, `light`, `dark`, `lime`).

## Данные и лёгкость

Заметки и задачи хранятся отдельно в `$XDG_DATA_HOME/lime-apps/`
(обычно `~/.local/share/lime-apps/`). Настройка темы —
`$XDG_CONFIG_HOME/lime-apps/appearance.ini` (обычно `~/.config/lime-apps/`).
Данные сохраняются атомарно с правами `0600`; повреждённое хранилище не затирается.
Перед ручным переносом файлов закрой соответствующее приложение.
Хранилище рассчитано на личное локальное использование; лимит — 10 000 записей.

Библиотеки GTK/GLib используются из системы и не включаются в каждый пакет.
Окна не запускают браузер, сетевые запросы, телеметрию или постоянный процесс.
Просмотрщик держит одно декодированное изображение, а часы приостанавливают
обновления на неактивных вкладках, когда они не нужны таймеру.
Реальное потребление памяти зависит от темы GTK, графического окружения и изображения.

## Проверки и участие

```sh
make test                 # вычисления, хранилище, версии
make smoke                # запуск всех окон; нужен графический сеанс
# В CI используется виртуальный X11-дисплей:
dbus-run-session -- xvfb-run -a make smoke
```

Релизный workflow публикует пакеты только после успешных проверок сборки,
установки, открытия окон и удаления. Удаление пакетов проверяется с сохранением
пользовательских данных. Автоматические проверки не заменяют полную ручную
проверку каждого рабочего стола.
